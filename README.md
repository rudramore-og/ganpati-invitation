# 🪔 Ganpati Bappa Morya 🙏

## 🌺 Ganpati Invitation Website

A beautiful and interactive **Ganpati invitation website** created to invite family, friends, and loved ones to celebrate the arrival of **Shri Ganpati Bappa**.

The website is designed with a festive Marathi theme and provides all the important details about the Ganpati celebration in a simple and elegant way.

---

## ✨ Features

* 🪔 Ganpati Bappa themed design
* 🌺 Marathi/Devanagari text
* 📜 Digital invitation
* 📅 Ganpati celebration details
* 🏠 Venue information
* 🎨 Festive animations and decorations
* 📱 Responsive design for mobile and desktop
* 🎵 Background music (if enabled)
* 📜 Smooth scrolling
* 🕉️ Traditional and festive visual elements

---

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling, animations and responsive design
* **JavaScript** – Interactive elements and functionality

## 🌸 Purpose

This project is a **digital Ganpati invitation** created to make inviting loved ones more convenient, memorable and festive.

Instead of sending a traditional invitation card, guests can simply open the website and view the complete celebration details.
